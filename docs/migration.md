旧客户端的 /events 与 /v1/events 只映射至近星轨道；/v2/events 要求明确游戏身份。旧库需用 import-legacy.mjs 指定新的目标文件，禁止原地改写。新的游戏分数与里程碑通过 manifest 扩展，不改公共接收器的游戏专属分支。
