# 隐私与保留期

默认公开配置没有接收地址，不发送线上数据；本地 dev 服务明确注入 Test 地址。匿名数据只包括游戏版本、平台、语言、粗粒度输入类型、合法渠道标签、计时和游戏/分享动作。没有邮箱、输入内容、完整 URL/referrer 或设备指纹；IP 仅在接收进程内以随机盐哈希用于分钟限流，不落库。

每个游戏有自己的匿名标识和待发队列。游戏站同一 origin 的退出偏好有意全站共用：在任一款游戏关闭统计，会清除当前 origin 下所有游戏的分析标识/队列；其他已打开文档收到 storage 通知后停止。已经发出的在途请求不能撤回，存储完全不可用时退出只影响当前文档。最高分、音量、语言不随分析退出删除。退出会同步旧 orbital-analytics-optout 标记并清除旧版分析队列，兼容旧版标签页和回退包；旧版的退出操作也会通知已打开的新版页面。

事件保留 90 天，服务启动及每日清理。待发事件最多 7 天/300 条，匿名 ID 不活动 90 天过期。示例始终 Test，离线 HTML 始终关闭统计。导出与备份需要同样按保留期管理。部署时不要在代理访问日志里保留 IP 或带参数的 URL。

分享的游戏固定地址由静态站路由维护，与事件日志保留期无关。日志过期后，旧链接仍应能打开游戏，但不承诺仍能精确匹配发送者。没有自动生成永久公开成绩页或上传成绩卡到云存储。

管理后台需要服务端密钥，仅在页面内存中持有。正式部署应放在与玩家游戏不同的 origin。发布前需在自有站和平台页面披露实际运营者、接收服务用途及联系渠道；当前没有编造联系邮箱。
